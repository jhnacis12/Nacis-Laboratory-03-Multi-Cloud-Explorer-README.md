# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is Google's public cloud platform. It provides services for computing, storage, networking, databases, artificial intelligence, machine learning, analytics, and containers.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. According to the current Google Cloud Global Locations page, Google Cloud has 43 regions and 130 zones. Regions are geographic areas, while zones are deployment areas within regions. :contentReference[oaicite:2]{index=2}

## Cloud Management Console

The Google Cloud Console is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services

1. **Compute Engine** - Provides virtual machines for running applications.
2. **Cloud Storage** - Provides object storage for files and data.
3. **Virtual Private Cloud (VPC)** - Provides networking for cloud resources.
4. **Google Kubernetes Engine (GKE)** - Provides managed Kubernetes clusters.

## Three Advantages

1. Strong artificial intelligence and machine learning capabilities.
2. Strong Kubernetes and container ecosystem.
3. Global infrastructure suitable for large-scale applications.

## Typical Enterprise Use Cases

- Artificial intelligence and machine learning
- Kubernetes and containerized applications
- Data analytics
- Web applications
- Large-scale distributed systems
