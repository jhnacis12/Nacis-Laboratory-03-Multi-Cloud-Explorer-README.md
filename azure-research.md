# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides services such as computing, storage, databases, networking, security, analytics, and artificial intelligence.

## Global Infrastructure

AWS has a global infrastructure organized into geographic Regions and Availability Zones. According to the current AWS Global Infrastructure page, AWS has 39 Geographic Regions and 124 Availability Zones. Each AWS Region contains multiple isolated Availability Zones designed to improve availability and fault tolerance.

## Cloud Management Console

The AWS Management Console is a web-based interface that allows users to create, configure, monitor, and manage AWS cloud resources and services.

## Four Core Services

1. **Amazon EC2** - Provides virtual servers for running applications.
2. **Amazon S3** - Provides object storage for files and data.
3. **Amazon VPC** - Provides virtual networking.
4. **AWS IAM** - Manages users, permissions, and access to AWS resources.

## Three Advantages

1. AWS provides a very wide range of cloud services.
2. AWS has a large global infrastructure.
3. AWS resources can scale according to application requirements.

## Typical Enterprise Use Cases

- Web and application hosting
- Data storage and backup
- Enterprise databases
- Global applications
- Data analytics and artificial intelligence
