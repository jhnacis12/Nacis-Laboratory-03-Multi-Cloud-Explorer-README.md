# Mission Reflection

## Which cloud platform impressed you the most?

The cloud platform that impressed me the most was Google Cloud Platform because of its strong artificial intelligence, machine learning, data, and Kubernetes services.

## What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide important cloud services such as virtual machines, storage, networking, databases, identity management, and container services. They also have global infrastructure and web-based management consoles.

## How do business requirements influence cloud platform selection?

Business requirements help determine which cloud provider is most suitable. Factors such as budget, existing technology, security, performance, scalability, location, and technical skills should be considered before choosing a provider.

## What did you learn from acting as a Cloud Solutions Consultant?

I learned that a cloud solutions consultant needs to understand the customer's requirements before recommending a cloud platform. The best cloud provider depends on the organization's specific needs.

## How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub portfolio became more organized and contains research and comparisons of AWS, Azure, and GCP. I also learned how to use Markdown files to document cloud computing activities.
